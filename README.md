# 💕 Un Rendez-vous Avec Moi

Un site web interactif et romantique pour demander un rendez-vous de façon originale!

## ✨ Caractéristiques

- 💕 **Demande Romantique** - Message poétique et sincère
- 🏃 **Bouton "Non" qui fuit** - La souris s'en rapproche? Il s'échappe! 😢
- 📅 **Choix de Date** - Elle sélectionne le jour parfait
- 🎬 **Choix d'Activité** - 5 options sympa
- 📧 **Envoi Automatique** - Les données sont envoyées par email
- 🎨 **Design Moderne** - Dégradé rouge et bleu romantique
- 🎊 **Animations** - Confettis, larmes qui tombent, cœur qui pulse

## 🎯 Activités Disponibles

- 🎬 **Cinéma**
- 🍽️ **Restaurant**
- 🍦 **Glacerie**
- 🚶 **Balade**
- 🏊 **Piscine**

## 🚀 Comment Utiliser

1. Ouvre `index.html` dans ton navigateur
2. Laisse la magie opérer! 💫

## 📧 Configuration Email

Le site envoie automatiquement les données à: **mfof1001@gmail.com**

Les données incluent:
- 📅 Date du rendez-vous
- 🎬 Activité choisie
- 📧 Email de confirmation
- ⏰ Date et heure d'envoi

## 🛠️ Technologies

- **HTML5** - Structure
- **CSS3** - Design et animations
- **JavaScript** - Interactivité
- **EmailJS** - Envoi automatique d'emails

## 💡 Fonctionnalités Spéciales

✅ Bouton "Non" impossible à cliquer (il fuit!)
✅ Confettis à chaque "Oui"
✅ Larmes qui tombent quand elle essaie de cliquer sur "Non"
✅ Messages personnalisés et poétiques
✅ Design responsive (marche sur mobile aussi)
